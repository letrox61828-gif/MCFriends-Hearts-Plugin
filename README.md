# McFriends-Hearts-Plugin

Separate blue-life system. Normal Minecraft health remains 20 HP / 10 red hearts.

- New player: 3 blue lives
- Player kill: -1 blue life
- 3 slots shown as active blue / inactive grey heart glyphs from the supplied resource pack
- 0 lives: kick with "Du hast keine Leben mehr!"
- 0-life player cannot join until an admin restores 1-3 lives
- Command: /nation hearts set <Spieler> <1|2|3>
- Lives persist in config.yml
